# DyLearn – tải video Douyin (dùng cá nhân)

1. Tạo repo mới trên GitHub, upload toàn bộ file trong thư mục này (nhớ cả thư mục `.github`).
2. Vào tab **Actions** → workflow **Build APK** chạy tự động (hoặc bấm *Run workflow*).
3. Chạy xong (~10-15 phút), mở lần chạy đó → mục **Artifacts** → tải `DyLearn-apk` → giải nén lấy file .apk và cài.
